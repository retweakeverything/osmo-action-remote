## First release

An open-source Android remote for the DJI Osmo Action 5 Pro over Bluetooth.
No DJI Mimo, no account, no cloud.

- Pair once on the camera, then reconnect automatically.
- Live status: battery, mode, SD space, recording time left, photos left.
- Record and stop, take photos, highlight tags, and switch modes.
- Workflows built from blocks (mode, photo, record for N seconds, wait,
  repeat, sleep), with templates, sharing as JSON, and background running.
- Sleep the camera. (Waking it from the app arrived in v0.2.0.)

## Install the app

1. Download `osmo-action-remote-0.1.0.apk` below on your Android phone (Android 12 or newer).
2. Open it. If Android asks, allow your browser or file manager to install unknown apps.
